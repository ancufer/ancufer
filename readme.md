# <center> Учебный проект курса Python-разработка платформы [Skillfactory](http://skillfactory.ru). </center>


### Описание учебного проекта   
В проекте реализована загрузка данных с помощью задач, работающих по расписанию (**airflow** **dag**), с сайта [open-meteo.com](https://open-meteo.com) в файл <span style="font-size:18px;">**weather.db**</span>. С помощью приложения (**Streamlit**) реализованы построение и фильтрация таблицы данных, отоброжение метрик, построение статистических графиков и построение графика прогноза погоды.



### Запуск задач работающих по расписанию и приложения **Streamlit**
* Для запуска задач по расписанию используются файлы, находящиеся в папке **airflow_sf**
    * **docker-compose.yaml** файл для настройки установки в Docker контейнера Airflow. После этой установки можно запустить веб интерфейс (**http://localhost:8080**), отслеживающий выполнение задач по расписанию
    * **dags\weather_dag.py** основной файл для работы по расписанию, в нём указываются задачи и условия их запуска по расписанию
    * **project\scripts\fetch_and_store.py** файлы с *python* кодом, функции этого файла фактически являются задачами файла **dags\weather_dag.py**, которые запускаются по расписанию
    * **project\data\weather.db** файл с данными с сайта [open-meteo.com](https://open-meteo.com). Данные в файл **weather.db** сохраняются с помощью *python* кода файла **project\scripts\fetch_and_store.py**

* Для работы приложения **Streamlit** используются семь файлов
    * **weather.db** файл с данными (**путь: airflow_sf\project\data\weather.db**)    
    * **app.py** основной модуль для запуска кода
    * **show_data.py** в файле код, отвечающий за отображение таблицы
    * **metrics.py** в файле код, отвечающий за отображение метрик погоды
    * **show_statistic.py** в модуле код, отвечающий за изображение статистических графиков
    * **predict.py**  в модуле код, отвечающий за изображение прогноза графиков
     * **default_data.py**  модуль с сзаданными значениями, используемыми в других модулях

* Для запуска приложения нужно сохранить указанную структуру в одной папке. Затем, установив и запустив приложение **Docker Desktop**, нужно в терминале в папке **airflow_sf** (где находится файл **docker-compose.yaml**) запустить команду **docker compose up -d**. Для отображения полученных данных нужно в корневой папке (где находится файл **app.py**) в терминале запустить команду 
**streamlit run main.py**

### Структура страницы приложения
На странице есть вкладки **Работа с таблицей**, **Метрики погоды**, **Статистические данные** и **Прогноз**.  


### Вкладка **Работа с таблицей**
На вкладке можно выбрать столбцы таблицы, для которых будут сформированы соответствующие им фильтры. Ниже на вкладке отображается Таблица с учётом применённых фильтров. Для удобства можно настроить просмотр таблицы. Можно настроить ***Число строк на странице*** и ***Номер страницы просмотра***.


### Вкладка **Метрики погоды**
На вкладке есть возможность выбора **города** и **периода отображения метрик**. Соответственно, отображаются метрики погоды для выбранного города и выбранного интервала дат.

### Вкладка **Статистические данные**
На вкладке есть возможность выбора **городов**, **параметра погоды** и **вида графика** для отображения статистических данных.


### Вкладка **Прогноз**
На вкладке есть возможность выбора **города**, **параметра погоды**,  **количество дней, используемых для построения прогноза**, **дату прогноза** и **количество дней, на которое нужно сделать прогноз**.  
Прогнозные значения, соответствующие заданным параметрам, для удобства сравнения отображаются на графике вместе с фактическими и прогнозными данными с сайта [open-meteo.com](https://open-meteo.com).  
Для построения прогноза используется Линейная регрессия ([Метод Наименьших Квадратов](https://ru.wikipedia.org/wiki/Метод_наименьших_квадратов?ysclid=mn9xs1p2uf30869991)), построенная на данных [скользящей средней](https://ru.wikipedia.org/wiki/Скользящая_средняя). Период скольжения 7 дней задан в модуле **default_data.py**.
